# 🏡 Las Ánforas Apart Hotel & Pádel

Bienvenido al repositorio oficial de la landing **Las Ánforas**, con motor de reservas integrado.  
Este sitio fue creado para mostrar las instalaciones del apart hotel, la cancha de pádel y permitir a los clientes reservar fácilmente desde la web.

---

## 🚀 Demo en línea
👉 [Ver sitio publicado](https://RadiantSkin.github.io/las-anforas-site/)  
*(El link se activa automáticamente con **GitHub Pages** cuando subas el `index.html` y configures la rama principal).*

---

## 📂 Estructura del proyecto

- `index.html` → Contiene todo el contenido de la landing (Hero, motor de reservas, galería, ubicación y footer).  
- `/images` → Guardar todas las fotos del complejo, logo y galería.  

---

## ⚙️ Cómo publicar en GitHub Pages
1. Subir los archivos a este repositorio (`index.html` y la carpeta `/images`).  
2. Ir a **Settings → Pages**.  
3. En **Source**, seleccionar:  
   - **Branch**: `main`  
   - **Folder**: `/root`  
4. Guardar los cambios.  

En unos segundos estará disponible en:  

---

## ✨ Tecnologías usadas
- **HTML5 + TailwindCSS** para la estructura y estilos.  
- **JavaScript (Vanilla)** para el motor de reservas y validaciones.  
- **SwiperJS** para la galería en carrusel.  
- **GitHub Pages** para el hosting gratuito.  

---

## 📌 Notas
- Asegúrate de que las imágenes en `/images` coincidan con los nombres configurados en `index.html`.  
- Si quieres usar un dominio propio (ej: `lasanforas.com.ar`), podés configurarlo desde **Settings → Pages → Custom domain**.
